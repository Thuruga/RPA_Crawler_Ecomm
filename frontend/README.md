# OmniPulse RPA — Frontend Dashboard

Interface web moderna construída com **React 19**, **TypeScript** e **Vite**, projetada sob o design system **Emerald / Fintech Dark**.

## Recursos

- **Monitor de Preços & Buy-Box**: Leitura em tempo real de preços, histórico e detecção de anomalias.
- **Busca Comparativa**: Comparação lado a lado de produtos em múltiplos e-commerces.
- **Auditoria Cruzada por SKU**: Rastreamento de ofertas concorrentes a partir de um código ou termo de referência.
- **Rastreador de Banners**: Visualização e extração de campanhas promocionais de concorrentes.
- **Acessibilidade & Performance**: Totalmente responsivo, suporte a navegação por teclado e sem bloqueios de vendor lock-in.

## Desenvolvimento

```powershell
npm install
npm run dev
```

Build para produção:

```powershell
npm run build
```
